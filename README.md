# Meeting Minute Chatbot

AI-powered chatbot that answers questions based on previous meeting records.

## Features

- Natural language question answering
- Source citations from meeting documents
- Role-based access control (Admin/Staff)
- Document management (upload, delete)
- User management
- Activity logging and audit trail

## Setup

The app uses SQLite for data storage and ChromaDB for vector search.
Default admin credentials: admin@organization.com / Admin@1234
